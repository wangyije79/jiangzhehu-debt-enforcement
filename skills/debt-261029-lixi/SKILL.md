# 借钱时的利息与利率

> 利率上限、无约定利息与砍头息复利

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「借钱可以约定多少利息？」「没约定利息还能不能要？」

**什么时候会用到它**：

- 借钱可以约定多少利息
- 没约定利息还能不能要
- 砍头息和复利合法吗

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```

```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非借贷与执行问题**：借款、担保、抵押质押、诉讼时效、强制执行以外的领域（如劳动争议、婚姻家事、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于借款利息的约定与上限判断、借期内利息与逾期利息的区分、未约定利息或约定不明时的处理、预先扣除利息（砍头息）的本金认定、将利息计入本金的复利争议，以及利息与违约金、其他费用叠加时的上限核算。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 约定借款利率 | 利率水平是否超过司法保护上限、是否写明计算口径 | 按合同成立时一年期贷款市场报价利率的四倍把握，超过部分不予支持 |
| 借款合同没有约定利息 | 双方是否均为自然人 | 一律视为没有利息；非自然人之间的借贷约定不明的，可按交易方式、交易习惯、市场利率确定 |
| 借款人逾期未还 | 是否约定了逾期利率 | 未约定的仍可主张逾期利息，一般参照司法保护上限把握 |
| 放款时预先扣除费用 | 借款人实际到账金额与借条载明金额是否一致 | 本金按实际借款数额认定，利息按实际本金计算，已多还部分可冲抵 |
| 将利息计入本金重新出借条 | 计入的利息是否实际支付、总额是否越过上限 | 未实际支付的利息一般需还原为实际本金；总额不得超过保护上限 |
| 同时约定利息、违约金与其他费用 | 各项合计是否越过保护上限 | 合计超过上限的部分不予支持，不能通过变换名目规避 |

## 六、操作步骤

1. 锁定合同成立时间，据此确定一年期贷款市场报价利率与四倍上限
2. 区分借期内利息与逾期利息，分别核对是否有约定
3. 核对利率条款是否写明年利率还是月利率，避免口径争议
4. 调取放款流水，比对借条载明金额与实际到账金额并列出全部扣除名目
5. 检查是否存在将利息计入本金重新出具借条的情形
6. 把利息、违约金、其他费用合计后与上限比对
7. 计算逾期利息的起算日：有约定按约定，未约定还款日期的从催告宽限期届满起算

## 七、常见误区

- 只写一个数字不写年利率还是月利率，事后被解释成月息
- 以为超过上限整份利息约定无效，其实只是超出部分不予支持
- 没有约定利息仍然主张借期内利息，白费一轮诉讼
- 忽略借款人未按约定日期收取借款，利息仍按约定日期起算
- 把砍头息当成合法的服务费，导致本金被虚高认定
- 逾期利息、违约金、其他费用叠加主张，合计突破保护上限

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
