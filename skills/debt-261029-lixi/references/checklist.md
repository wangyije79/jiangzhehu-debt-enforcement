# 检查表

## 事实与材料自查

- [ ] 利率条款是否写明计算口径与适用期间
- [ ] 是否核对了合同成立时的报价利率与四倍上限
- [ ] 借期内利息与逾期利息是否分别约定
- [ ] 放款流水是否已调取，实际到账金额是否清楚
- [ ] 是否存在以服务费、咨询费等名义预先扣除的情形
- [ ] 是否有将未付利息计入本金重新出具借条的情况
- [ ] 利息、违约金与其他费用的合计是否越过上限
- [ ] 还款日期是否写明，催告痕迹是否保留

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
