# 检查表

## 事实与材料自查

- [ ] 借款人、出借人是否写全名并加身份证号
- [ ] 金额大小写是否一致，是否加了“整”字
- [ ] 款项交付方式是否写明，转账回单是否留存
- [ ] 利率是否写明是年利率还是月利率
- [ ] 还款日期、逾期责任是否写明，还是留了空白
- [ ] 签名是否本人所签并按指印，出具日期是否填写
- [ ] 是否有涂改痕迹，涂改处是否双方按指印确认
- [ ] 送达地址确认条款是否已经加上

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
