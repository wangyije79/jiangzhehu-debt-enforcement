# 借条怎么写才管用

> 借条与欠条的区别、必备要素与补救

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「借条和欠条差一个字，时效差三年？」「借条上必须写清哪几项？」

**什么时候会用到它**：

- 借条和欠条差一个字，时效差三年
- 借条上必须写清哪几项
- 借条写错了还能补救吗

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
借条和欠条差一个字，时效差三年？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份离婚起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非借贷与执行问题**：借款、担保、抵押质押、诉讼时效、强制执行以外的领域（如劳动争议、婚姻家事、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于借条的起草与自查、借条与欠条的选择、凭证名称引发的时效起算争议、构成要素缺失（身份信息、金额、交付方式、利息与还款日期）的补正，也适用于借条写错、代签、只有照片等瑕疵凭证的证据补救与时效中断处理。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 要写一张借款凭证 | 能不能确定款项已经交付、何时到期 | 优先用借条并写明还款日期；借条需同时证明借贷合意与款项交付 |
| 手里只有没写还款日期的欠条 | 欠款在出具时是否已经到期 | 能证明到期的从到期日起算时效，不能证明的从出具欠条之日起算，风险明显大于借条 |
| 凭证没写还款日期 | 能否依民法典第五百一十条、第五百一十一条确定履行期限 | 不能确定的，时效从债权人要求履行义务的宽限期届满之日起算 |
| 借条上名字、金额、日期有误 | 错误能否与真实身份或真实数额建立对应 | 通过补签还款协议、对账确认或双方更正加按指印补正 |
| 只有照片或代签，没有原件 | 能否用转账记录、聊天记录、还款记录形成证据链 | 能形成链条的可主张；不能的需先补签确认再考虑起诉 |
| 对方以超过诉讼时效抗辩 | 期间有无中断事由、届满后对方有无认账或还款 | 有送达痕迹的催告产生中断效力；届满后对方同意履行或自愿履行的，不得再以时效抗辩 |

## 六、操作步骤

1. 先判断凭证类型：是借条、欠条还是收条，借条与欠条的法律基础不同
2. 核对身份信息：双方全名、身份证号、联系方式是否写全并对得上
3. 核对金额：阿拉伯数字与中文大写是否一致，结尾是否加“整”字
4. 核对交付证据：转账回单或现金交付的书面确认是否在手
5. 核对利息与期限：利率口径、还款日期、逾期责任是否写明
6. 检查送达地址确认条款是否加上，是否注明适用于诉讼文书送达
7. 发现瑕疵的按类型补救，并算出起算日与届满日、设置催告提醒

## 七、常见误区

- 只写小名、简称或者只写姓，事后无法锁定借款人主体
- 现金交付却没有对方收到款项的任何书面确认
- 利率只写一个数字，不写年利率还是月利率，被对方解释成月息
- 借条上不写还款日期，也不做任何催收，等到想起来已经过了三年
- 只口头催款，拿不出送达痕迹，中断效力无法证明
- 金额大小写不一致还不做更正，事后各说各话

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
