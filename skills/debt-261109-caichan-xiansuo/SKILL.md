# 自己怎么找财产线索

> 房产车辆、银行流水与悬赏公告

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「怎么查对方名下有没有房子？」「怎么查对方的银行账户？」

**什么时候会用到它**：

- 怎么查对方名下有没有房子
- 怎么查对方的银行账户
- 悬赏公告怎么申请

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
怎么查对方名下有没有房子？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份离婚起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非借贷与执行问题**：借款、担保、抵押质押、诉讼时效、强制执行以外的领域（如劳动争议、婚姻家事、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于申请执行人自行查找与提交财产线索的环节：不动产线索的提交与查封登记、共有房产的处理与代位析产、银行账户线索的来源与协助执行、持续收入的扣留提取、保全阶段的查控系统申请，以及悬赏公告与审计调查的申请与适用。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 想查对方名下房产 | 能否提供明确具体的线索 | 线索明确具体的七日内核实；无法自行查明的可以申请法院调查 |
| 房产登记在第三人名下 | 第三人是否书面确认属于被执行人 | 书面确认的可以查封；属于共有的可以查封并代位提起析产诉讼 |
| 想查对方银行账户 | 是否属于个人金融信息 | 个人无权直接查询，应通过法院网络查控或协助执行通知书办理 |
| 对方有工资、租金等持续收入 | 收入是否已支取 | 尚未支取的向所在单位发协助执行通知书扣留提取；已转存款的责令交出存单或裁定提取 |
| 常规手段均未发现财产 | 是否愿意设定并支付悬赏金 | 可以书面申请发布悬赏公告，法院十日内决定是否准许 |
| 怀疑存在账目造假或出资不实 | 是否有初步线索 | 可以书面申请委托审计，法院十日内决定是否准许；审计费由申请执行人预交 |

## 六、操作步骤

1. 把已有材料里的地址、账户、车牌等信息整理成线索清单
2. 按财产调查表要求逐项填写，写到可核查的颗粒度后提交法院
3. 对不动产线索，跟进核实结果并申请查封及查封登记；登记在第三人名下或共有的，准备书面确认材料或提起代位析产诉讼
4. 对账户线索，申请启动网络查控；保全阶段即可申请查询冻结
5. 对持续收入，申请向付款单位发出协助执行通知书按月扣留提取
6. 常规手段用尽的，书面申请悬赏公告或委托审计
7. 记住查封冻结期限（不动产三年、存款一年、动产两年），到期前申请续行

## 七、常见误区

- 只写对方在某银行有存款，不提供开户行与账号线索
- 查封后不跟进登记手续，顺位被其他债权人抢先
- 忽略查封期限，到期未续行导致效力消灭
- 对登记在配偶或亲属名下的房产，不做共有或代持的证据准备
- 悬赏金定得过高，或在法院已掌握财产后仍申请悬赏
- 以为借助他人名义提交线索也能领取悬赏金

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
