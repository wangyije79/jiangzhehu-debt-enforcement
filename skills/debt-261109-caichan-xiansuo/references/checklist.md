# 检查表

## 事实与材料自查

- [ ] 财产调查表是否已提交，线索是否具体到地址与账号
- [ ] 查封后是否确认登记机关已办理查封登记
- [ ] 土地与房屋登记机关不同时是否分别办理查封登记
- [ ] 共有人是否已通知，是否需要代位提起析产诉讼
- [ ] 账户线索是否已提交并申请启动网络查控
- [ ] 持续收入是否已申请按月扣留提取
- [ ] 查封冻结期限是否已登记在案并安排续行
- [ ] 悬赏或审计申请是否具备条件、金额与费用是否算过

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
