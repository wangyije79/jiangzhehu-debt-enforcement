# 起诉欠钱不还的准备

> 起诉材料、管辖法院与诉讼成本

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「起诉欠钱不还要准备什么？」「该去哪个法院起诉？」

**什么时候会用到它**：

- 起诉欠钱不还要准备什么
- 该去哪个法院起诉
- 打这个官司要花多少钱

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
起诉欠钱不还要准备什么？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份离婚起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非借贷与执行问题**：借款、担保、抵押质押、诉讼时效、强制执行以外的领域（如劳动争议、婚姻家事、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于自然人之间欠款纠纷的起诉准备，包括被告身份信息的补齐、本金与利息的核算、证据材料的分类编号、审理阶段与执行阶段管辖的确定、财产保全的申请与担保安排，以及诉讼费、保全担保、执行申请费等成本的预估。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 准备起诉 | 有没有明确的被告身份信息与具体诉讼请求 | 主体与请求明确的可以立案；缺项的先用转账凭证等材料补齐 |
| 核算本金 | 实际交付金额与借条金额是否一致 | 利息预先在本金中扣除的，按实际借款数额返还并计算利息 |
| 主张利息 | 合同有无利息约定 | 有约定的按约定但不得违反国家有关规定；未约定的视为没有利息 |
| 确定审理管辖 | 有无约定管辖、被告住所地与合同履行地在哪 | 按既有规则选择连接点，一般由被告住所地或合同履行地法院管辖 |
| 担心对方转移财产 | 是否需要并在哪个阶段申请财产保全 | 可申请诉前或诉中保全，诉前保全采取措施后三十日内须起诉 |
| 判决生效后对方不履行 | 财产在何处、是否已过申请执行期间 | 向第一审法院或财产所在地同级法院申请执行，期间为二年 |

## 六、操作步骤

1. 补齐被告的姓名、身份号码、住址、联系方式
2. 核算本金，核对是否存在预扣利息
3. 核对利息约定，确定利息与逾期利息的主张方式
4. 把证据分成借贷关系、款项交付、催收时效、主体材料四类
5. 按规则确定审理管辖法院，必要时同步安排保全
6. 估算诉讼费、保全担保与执行申请费，评估成本
7. 写好起诉状，明确诉讼请求、事实与理由后提交

## 七、常见误区

- 被告身份信息不完整，立案或执行阶段卡住
- 把预扣的利息也当成本金主张
- 没有利息约定却硬写利息请求
- 在不确定管辖的情况下随便选法院，导致移送或拖延
- 申请诉前保全后超过三十日不起诉
- 判决生效后长期不申请执行，接近或超过二年期间

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意

借贷与执行案件高度依赖证据与时效。以下情形建议咨询执业律师：

- 涉及金额较大，或已进入执行程序、需要保全或追加被执行人的

- 对方有转移财产迹象，或已被列为失信、限高的
- 需要判断诉讼时效、管辖法院、执行期限等程序节点的
