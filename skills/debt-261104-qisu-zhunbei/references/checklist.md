# 检查表

## 事实与材料自查

- [ ] 被告身份信息是否完整、准确
- [ ] 本金是否按实际交付金额计算
- [ ] 是否核对过借条与聊天记录中关于利息的约定
- [ ] 证据是否分类编号并写明证明目的
- [ ] 是否确认过有无约定管辖条款
- [ ] 是否需要保全，是否了解担保方式与成本
- [ ] 是否核算过诉讼费与执行申请费
- [ ] 判决生效后是否记得在二年内申请执行

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
