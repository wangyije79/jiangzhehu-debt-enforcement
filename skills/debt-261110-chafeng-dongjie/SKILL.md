# 查封冻结与扣划

> 可执行财产范围、唯一住房与扣划

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「法院能查封哪些财产？」「唯一住房能不能被执行？」

**什么时候会用到它**：

- 法院能查封哪些财产
- 唯一住房能不能被执行
- 冻结的存款怎么扣划

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
法院能查封哪些财产？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份离婚起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非借贷与执行问题**：借款、担保、抵押质押、诉讼时效、强制执行以外的领域（如劳动争议、婚姻家事、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于查封、扣押、冻结与扣划的实务操作：可查封财产的范围与第三人名下财产的处理、不得明显超标的的要求、查封效力及于从物与替代物、轮候查封与顺位、唯一住房的查封与拍卖条件及居住保障方案、存款冻结期限与扣划程序、协助执行单位的责任。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 准备查封财产 | 财产登记在谁名下 | 登记在被执行人名下或由被执行人占有的可以直接查封；登记在第三人名下的需第三人书面确认 |
| 财产已有抵押或质押 | 是否仍有剩余价值 | 仍可查封扣押，变价款在抵押权人等优先受偿后就余额部分清偿申请执行人的债权 |
| 财产已被其他法院查封 | 是否仍有受偿可能 | 可以办理轮候查封，在先查封解除时轮候查封自动生效 |
| 执行标的是唯一住房 | 是否属于生活所必需的居住房屋 | 可以查封但不得拍卖；符合异议复议规定第二十条三种情形的可以拍卖 |
| 想拍卖唯一住房 | 是否已提出居住保障方案 | 需按当地廉租住房保障面积标准提供居住房屋，或同意从变价款中扣除五至八年租金 |
| 冻结期限即将届满 | 是否已申请续行 | 应在届满前办理续行手续；银行存款一年、动产两年、不动产与其他财产权三年，逾期效力消灭 |

## 六、操作步骤

1. 确认查封裁定已作出并送达，协助执行通知书已送达协助执行人
2. 对已登记财产跟进查封登记并留存回执，同时核算查封数额与债权额、执行费用是否相当
3. 财产已被查封的，申请轮候查封并登记顺位
4. 对唯一住房，先查扶养关系与房产转让记录，再提出居住保障方案
5. 对存款，申请冻结后推动作出扣划裁定并发协助执行通知书
6. 建立期限台账，冻结到期前提出续行申请
7. 对拒不协助的单位，申请责令限期追回并主张其承担责任

## 七、常见误区

- 以为有抵押的财产不能执行，放弃申请查封
- 查封后不跟进登记手续，被其他债权人抢先登记
- 查封数额明显超标，引发对方异议并被解除超标部分
- 认为唯一住房一律不能执行，或一律可以执行
- 工资账户全额冻结，未保留生活必需费用
- 冻结到期未办理续行，效力消灭后资金被划走

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
