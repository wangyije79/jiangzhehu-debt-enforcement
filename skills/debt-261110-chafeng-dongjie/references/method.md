# 分析框架与操作方法

## 判断逻辑

### 节点 1：准备查封财产

- **判断标准**：财产登记在谁名下
- **处理结论**：登记在被执行人名下或由被执行人占有的可以直接查封；登记在第三人名下的需第三人书面确认

### 节点 2：财产已有抵押或质押

- **判断标准**：是否仍有剩余价值
- **处理结论**：仍可查封扣押，变价款在抵押权人等优先受偿后就余额部分清偿申请执行人的债权

### 节点 3：财产已被其他法院查封

- **判断标准**：是否仍有受偿可能
- **处理结论**：可以办理轮候查封，在先查封解除时轮候查封自动生效

### 节点 4：执行标的是唯一住房

- **判断标准**：是否属于生活所必需的居住房屋
- **处理结论**：可以查封但不得拍卖；符合异议复议规定第二十条三种情形的可以拍卖

### 节点 5：想拍卖唯一住房

- **判断标准**：是否已提出居住保障方案
- **处理结论**：需按当地廉租住房保障面积标准提供居住房屋，或同意从变价款中扣除五至八年租金

### 节点 6：冻结期限即将届满

- **判断标准**：是否已申请续行
- **处理结论**：应在届满前办理续行手续；银行存款一年、动产两年、不动产与其他财产权三年，逾期效力消灭

## 操作步骤

1. 确认查封裁定已作出并送达，协助执行通知书已送达协助执行人
2. 对已登记财产跟进查封登记并留存回执，同时核算查封数额与债权额、执行费用是否相当
3. 财产已被查封的，申请轮候查封并登记顺位
4. 对唯一住房，先查扶养关系与房产转让记录，再提出居住保障方案
5. 对存款，申请冻结后推动作出扣划裁定并发协助执行通知书
6. 建立期限台账，冻结到期前提出续行申请
7. 对拒不协助的单位，申请责令限期追回并主张其承担责任

## 常见误区

- 以为有抵押的财产不能执行，放弃申请查封
- 查封后不跟进登记手续，被其他债权人抢先登记
- 查封数额明显超标，引发对方异议并被解除超标部分
- 认为唯一住房一律不能执行，或一律可以执行
- 工资账户全额冻结，未保留生活必需费用
- 冻结到期未办理续行，效力消灭后资金被划走

## 说明

查封冻结这件事，做对比做多重要。立案之后先解决三个问题：财产在哪里、登记在谁名下、有没有在先查封。这三个问题清楚了，后面的扣划与拍卖才谈得上效率。
