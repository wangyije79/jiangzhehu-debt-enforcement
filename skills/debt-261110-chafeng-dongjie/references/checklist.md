# 检查表

## 事实与材料自查

- [ ] 查封裁定与协助执行通知书是否已送达并生效
- [ ] 已登记财产是否办理了查封登记手续
- [ ] 查封数额是否与债权额及执行费用相当
- [ ] 是否有其他法院在先查封，是否需要办理轮候查封
- [ ] 执行标的是否属于生活所必需居住房屋，是否已提出保障方案
- [ ] 存款账户是否已冻结，扣划所需裁定与通知是否已办理
- [ ] 是否已保留被执行人及其所扶养家属的生活必需费用
- [ ] 三类查封冻结期限是否已登记并安排续行

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
