# 检查表

## 事实与材料自查

- [ ] 保全申请书是否写明双方身份、送达地址与联系方式
- [ ] 是否写明请求保全数额或争议标的，并与债权额匹配
- [ ] 是否提供明确的被保全财产信息或具体线索
- [ ] 是否写明担保财产信息或不需要提供担保的理由
- [ ] 诉前保全是否已确认三十日的起算日与届满日
- [ ] 担保方式是否已落实，追加担保通知是否已处理
- [ ] 保全期限届满前七日是否已申请续行保全
- [ ] 撤诉、和解、诉请被驳回后是否已申请解除并留痕

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
