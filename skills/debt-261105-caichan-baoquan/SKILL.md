# 财产保全

> 诉前保全、担保要求与保全错误的赔偿

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「起诉前能不能先冻结对方财产？」「申请保全要交多少担保？」

**什么时候会用到它**：

- 起诉前能不能先冻结对方财产
- 申请保全要交多少担保
- 保全错了要不要赔

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
起诉前能不能先冻结对方财产？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份离婚起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非借贷与执行问题**：借款、担保、抵押质押、诉讼时效、强制执行以外的领域（如劳动争议、婚姻家事、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于起诉前与诉讼中的财产保全：保全条件与提出时间、申请书应载明事项、担保比例与担保方式（财产担保、责任保险、独立保函）、可以不提供担保的情形、解除保全的时点与义务、保全错误的赔偿责任，以及被保全人的复议与异议救济路径。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 想起诉前先冻对方财产 | 是否存在对方转移财产等紧急情形 | 符合紧急情形的可以申请诉前保全，且须在采取措施后三十日内起诉或申请仲裁 |
| 诉前保全三十日内未起诉 | 保全措施是否仍在 | 应当及时申请解除保全，未及时申请须赔偿被保全人损失 |
| 诉讼中申请保全 | 法院是否责令提供担保 | 担保数额不超过请求保全数额的百分之三十，系争议标的的不超过争议标的价值的百分之三十 |
| 诉前申请保全 | 是否属于情况特殊 | 原则上提供相当于请求保全数额的担保，情况特殊可酌情处理 |
| 担保能力不足 | 是否有可用的替代担保方式 | 可用财产担保、保全责任保险、金融机构独立保函；仍不足则缩减保全数额，避免追加不能被解除 |
| 诉请被驳回、撤诉或和解 | 是否已及时申请解除 | 应在五日内（紧急情形四十八小时内）办结解除；未及时申请可能承担赔偿责任 |

## 六、操作步骤

1. 判断保全时点：起诉前走诉前保全，起诉时或起诉后走诉讼中保全
2. 固定紧急情形的证据：转账记录、财产挂牌信息、沟通记录
3. 按财产保全规定第一条逐项撰写申请书，重点写实被保全财产信息，并主张免担保情形
4. 计算保全数额与担保比例，选定担保方式并准备担保书或保单
5. 跟踪裁定时间：一般五日内裁定，情况紧急四十八小时内裁定
6. 诉前保全的，在三十日内起诉或申请仲裁，并同步办理续行保全
7. 出现撤诉、和解、诉请被驳回等情形，第一时间书面申请解除保全

## 七、常见误区

- 以为诉前保全没有期限，忘记三十日内起诉或申请仲裁
- 把诉讼中三成上限当成一律三成，或把诉前当成三成
- 申请书只写担心，不写对方正在转移财产的具体迹象
- 收到追加担保通知后不理，导致保全被解除或部分解除
- 诉请被驳回、撤诉后不申请解除，坐等对方索赔
- 保全数额明显超标的，给赔偿风险留下缺口

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
