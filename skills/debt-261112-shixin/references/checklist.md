# 检查表

## 事实与材料自查

- [ ] 是否已区分限高与失信，确认各自的依据条款
- [ ] 失信情形是否对应到第一条的具体项
- [ ] 是否存在第三条规定的不得纳入情形
- [ ] 是否确认纳入期限及起算、届满时间
- [ ] 履行或纠正行为的凭证是否已固定并提交
- [ ] 申请执行人是否愿意出具书面删除申请
- [ ] 属于错误纳入的，是否已提出撤销或更正请求
- [ ] 是否同步核对限高与征信记录是否随之调整

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
