# 失信被执行人

> 失信与限高的区别、后果与撤销

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「失信和限高到底有什么区别？」「上了失信名单有什么后果？」

**什么时候会用到它**：

- 失信和限高到底有什么区别
- 上了失信名单有什么后果
- 怎么从失信名单上撤下来

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
失信和限高到底有什么区别？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份离婚起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非借贷与执行问题**：借款、担保、抵押质押、诉讼时效、强制执行以外的领域（如劳动争议、婚姻家事、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于执行程序中被纳入失信被执行人名单与限制消费措施的区分与应对，包括两类措施的纳入条件与相互触发关系、名单公布与部门通报的后果、不得纳入的排除情形、纳入期限与提前删除，以及删除、撤销、更正三条退出路径。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 被执行人未按执行通知履行给付义务 | 是否已届期未履行 | 人民法院可以采取限制消费措施 |
| 是否应当纳入失信名单 | 是否属于失信规定第一条列举的六种情形之一 | 属于的应当纳入并公布；不属于的只能限高 |
| 主张“暂时没有履行能力” | 是否属于有履行能力而拒不履行 | 需结合财产状况与消费情况判断，单纯陈述困难一般不足以否定 |
| 财产已被查封冻结且足以清偿 | 是否属于第三条规定不得纳入的情形 | 不得依据“有履行能力而拒不履行”纳入失信名单 |
| 失信信息的退出 | 属于应当删除的七种情形，还是属于错误纳入或信息不准确 | 应当删除的在三个工作日内删除；错误纳入的撤销，记载不准确的更正 |
| 失信存在纳入期限 | 是否属于第一条第二项至第六项情形 | 期限一般为二年，情节严重或多项的可延长一至三年，届满应当删除 |

## 六、操作步骤

1. 先判断面对的是限高、失信还是两者并存，核对文书与依据条款
2. 属于失信的，逐项比对失信规定第一条六种情形
3. 核对是否存在第三条四类不得纳入的情形，作为抗辩或撤销依据
4. 查清纳入是否有期限、起算日与届满日
5. 有履行或纠正行为的，向执行法院提交材料申请提前删除
6. 属于错误纳入或信息不准确的，按第九条申请撤销或更正
7. 争取申请执行人书面申请删除，并留意六个月内的限制规则

## 七、常见误区

- 把失信与限高当成同一件事，错用解除路径
- 以为失信是终身的，忽略纳入期限与提前删除
- 认为“一时没钱”就等于“有履行能力而拒不履行”
- 只履行不申请，名单仍挂在公示渠道
- 忽略信息会被通报到政府部门、行业协会与征信机构这一层后果
- 被错误纳入后只等期限届满，不走撤销程序

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
