# 没有借条怎么要钱

> 无借条起诉、转账凭证与录音证据

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「没有借条能起诉要钱吗？」「微信转账记录算不算证据？」

**什么时候会用到它**：

- 没有借条能起诉要钱吗
- 微信转账记录算不算证据
- 只有通话录音能打赢吗

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
没有借条能起诉要钱吗？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份离婚起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非借贷与执行问题**：借款、担保、抵押质押、诉讼时效、强制执行以外的领域（如劳动争议、婚姻家事、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于自然人之间没有借条、借条内容不完整、只有微信转账记录、只有聊天记录或者只有通话录音的欠款追讨；也适用于现金交付、金额不明确、对方否认借款关系的常见情形，以及起诉前需要判断证据够不够用、还需不需要补充固定的场合。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 手上没有借条 | 有没有其他材料能同时证明款项交付与借贷合意 | 能证明的可以起诉主张返还；证明不了的先补强再起诉 |
| 只有转账凭证 | 被告是否抗辩款项系还款、投资款、货款或赠与 | 原告需就借贷合意进一步举证，举证不足的承担不利后果 |
| 借条未写还款日期 | 能否依民法典第五百一十条、第五百一十一条确定履行期限 | 能确定的从履行期限届满之日起算时效；不能确定的从催告宽限期届满之日起算 |
| 对方在第一次被主张权利时明确拒付 | 有无明确表示不履行的表述或记录 | 时效从明确表示不履行义务之日起计算 |
| 只有通话录音 | 能否识别说话人身份、内容是否完整、取得方式是否合法 | 三项均满足的可作为认定事实的参考；缺失的需其他材料补强 |
| 已经拖了一段时间 | 有没有做过能证明到达的催收 | 以信件或数据电文方式主张权利并到达对方的，产生时效中断效力 |

## 六、操作步骤

1. 先分类盘点：把手上的材料分成“证明交付”和“证明借贷合意”两堆
2. 导出完整转账凭证或银行流水，保留交易单号、金额、时间
3. 把收款账号与对方实名信息做一次对应，锁定被告身份
4. 补齐借贷合意：聊天记录、通话录音、转账备注、付息记录
5. 做一次能证明到达的催收，同时固定发送与到达的证据
6. 按时间顺序编号成册，每份材料写明证明目的
7. 核算本金与利息，确定诉讼请求金额后再决定起诉时点

## 七、常见误区

- 以为没有借条就不能起诉，直接放弃主张
- 把转账记录当成万能证据，忽略借贷合意的举证
- 只截一张转账成功截图，不导出带双方账号的完整账单
- 用剪辑过的录音或只留有利片段的聊天记录
- 口头催收不留痕，事后无法证明主张过权利
- 在没算清时效的情况下反复协商，把时间耗掉

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
