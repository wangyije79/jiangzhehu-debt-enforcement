# 检查表

## 事实与材料自查

- [ ] 是否已经确认被告的姓名、身份号码、住址与联系方式
- [ ] 转账凭证是否显示了双方账号，而不只是一张成功截图
- [ ] 收款账号是否能与被告本人对应上
- [ ] 是否找到任何指向“借款”的文字、语音或备注
- [ ] 是否核对过对方有没有还过一部分或者付过利息
- [ ] 是否做过一次能证明到达的催收并保留凭证
- [ ] 是否判断过时效的起算点与剩余期限
- [ ] 诉讼请求的金额是否含利息并按规则核算过

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
