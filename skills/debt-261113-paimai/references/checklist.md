# 检查表

## 事实与材料自查

- [ ] 是否已确认拍卖平台与拍卖方式符合规定
- [ ] 评估价、起拍价、保留价是否核对，降价幅度是否在限额内
- [ ] 公告期是否满足动产十五日、不动产或其他财产权三十日
- [ ] 公示信息与特别提示是否齐备，是否已申请实地看样
- [ ] 保证金是否在起拍价的百分之五至百分之二十区间并以实名交纳
- [ ] 是否存在不得竞买的主体情形
- [ ] 佣金与税费承担方式是否已算入成本
- [ ] 对拍卖的异议是否在标的执行终结前提出

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
