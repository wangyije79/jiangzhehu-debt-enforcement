# 司法拍卖与变卖

> 拍卖流程、参与竞买与价格异议

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「房子被拍卖要走哪些流程？」「司法拍卖怎么参与竞买？」

**什么时候会用到它**：

- 房子被拍卖要走哪些流程
- 司法拍卖怎么参与竞买
- 拍卖价格太低能反对吗

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
房子被拍卖要走哪些流程？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份离婚起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非借贷与执行问题**：借款、担保、抵押质押、诉讼时效、强制执行以外的领域（如劳动争议、婚姻家事、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于执行程序中对被执行人财产的拍卖、变卖与网络司法拍卖，包括查封后变价的顺序、评估与保留价的确定、公告与公示要求、竞买资格与保证金、成交与悔拍的后果、流拍后的再次拍卖与变卖，以及提出异议请求撤销拍卖的路径与期限。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 财产已被查封、扣押、冻结 | 是否需要变价处理 | 应当及时拍卖、变卖或采取其他执行措施，变价首先采取拍卖方式 |
| 确定拍卖方式 | 是否属于必须通过其他途径处置或不宜网络拍卖的情形 | 原则上应当采取网络司法拍卖方式 |
| 确定起拍价与保留价 | 是否经过评估 | 评估价即为第一次拍卖保留价；起拍价不得低于评估价或市价的百分之七十 |
| 第一次拍卖流拍 | 是否有人出价、申请执行人是否接受抵债 | 三十日内在同一平台再次拍卖，降价不超过前次起拍价百分之二十；再流拍可依法变卖 |
| 判断能否请求撤销拍卖 | 是否存在展示严重失实、恶意串通、资格欠缺或程序严重违法 | 符合的应当支持撤销；仅认为价格偏低的一般不予支持 |
| 买受人成交后逾期未付价款 | 是否在公告确定期限内交付剩余价款 | 保证金不予退还并用于弥补差价与费用，重新拍卖时原买受人不得参加 |

## 六、操作步骤

1. 核对查封时间与期限，明确财产是否已进入变价阶段
2. 核对评估报告与保留价，审查是否评估、是否征询当事人意见
3. 核对公告期与公告内容，看公示信息与特别提示是否齐备
4. 参拍前申请实地看样，核对权利负担、欠费与交付状况
5. 按起拍价的百分之五至百分之二十准备并以实名交纳保证金
6. 成交后在公告确定的期限内交付剩余价款，避免悔拍
7. 对价格或程序有异议的，在标的执行终结前提出书面异议并附证据

## 七、常见误区

- 只在成交后抱怨价格低，不在期限内对程序问题提出异议
- 忽略公告期长短，误以为公告出来就能随时参拍
- 不看特别提示，成交后以“不知有瑕疵”为由要求撤销
- 误以为付款即取得所有权，实际以成交裁定送达为准
- 悔拍后以为只是损失一笔保证金，实际还要承担重新拍卖的差价、费用与原佣金
- 忽略网络拍卖本身形成的税费与实际欠费，成本算漏

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
