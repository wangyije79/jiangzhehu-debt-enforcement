# 法院怎么查财产

> 网络查控、报告财产令与调查措施

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「法院能查到对方哪些财产？」「网络查控系统查的是什么？」

**什么时候会用到它**：

- 法院能查到对方哪些财产
- 网络查控系统查的是什么
- 报告财产令有什么用

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
法院能查到对方哪些财产？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份离婚起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非借贷与执行问题**：借款、担保、抵押质押、诉讼时效、强制执行以外的领域（如劳动争议、婚姻家事、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于执行阶段的财产调查全流程：申请执行人提供线索的方式与核实期限、被执行人报告财产令的发出与查询、网络执行查控系统的覆盖范围与效力、搜查、传唤拘传、审计调查、悬赏公告等手段的适用，以及终本后的定期查询与恢复执行衔接。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 刚立案 | 是否已经有可供执行的财产线索 | 应当填写财产调查表提供线索；线索明确具体的七日内核实，情况紧急的三日内核实 |
| 被执行人未按执行通知履行 | 是否已发出报告财产令 | 金钱债权执行中报告财产令应与执行通知同时发出，未发出的可申请补发 |
| 想了解对方财产状况 | 网络查控系统是否已启动 | 可以请求法院启动网络查控并反馈结果；系统查询与现场调查具有同等法律效力 |
| 怀疑对方转移、隐匿财产 | 是否有具体指向 | 可以申请搜查、传唤或拘传相关人员，被执行人是公司的可申请委托审计 |
| 常规调查均未发现财产 | 是否符合发布悬赏公告的条件 | 可以书面申请发布悬赏公告，由法院十日内决定是否准许 |
| 案件已终结本次执行程序 | 是否需要继续关注 | 终本后五年内执行法院每六个月查询一次财产，发现财产可申请恢复执行 |

## 六、操作步骤

1. 立案后立即填写财产调查表，把线索写到账户、门牌号、车牌号的颗粒度
2. 确认报告财产令已发出，并申请查询被执行人提交的财产报告
3. 请求法院启动网络执行查控系统，索取查询结果反馈
4. 对拒绝报告、虚假报告的，书面申请罚款、拘留并申请纳入失信名单
5. 隐匿财产、账簿拒不交出的，申请搜查或申请传唤、拘传相关人员；被执行人是公司的，申请委托审计
6. 常规手段用尽的，申请发布悬赏公告查找可供执行的财产
7. 终本后跟踪每六个月的定期查询结果，发现财产立即申请恢复执行

## 七、常见误区

- 把提供财产线索当成可选项，坐等法院代劳
- 收到电子法律文书或电子查询结果后怀疑其效力
- 只看银行存款余额，忽略股权、应收账款、投资收益
- 发现对方漏报、假报后仅口头反映，不提交书面申请
- 审计费用预交后不主张由对方承担
- 案件终本后不再跟进，错过定期查询发现的财产

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
