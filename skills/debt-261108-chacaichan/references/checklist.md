# 检查表

## 事实与材料自查

- [ ] 财产调查表是否已提交，线索是否具体可查
- [ ] 报告财产令是否已发出，报告内容是否已查询比对
- [ ] 网络查控是否已启动，反馈结果是否已取得
- [ ] 被执行人是否存在拒报、假报、漏报情形
- [ ] 是否评估过搜查、传唤、审计等手段的适用性
- [ ] 涉及公司的，是否核查股东出资与股权情况
- [ ] 是否已申请对拒不履行的被执行人采取信用惩戒
- [ ] 案件终本后是否仍在跟进定期查询结果

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
