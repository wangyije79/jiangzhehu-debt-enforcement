# 执行和解与执行担保

> 和解效力、不履行救济与执行担保

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「执行中能不能跟对方和解？」「和解后对方又不履行怎么办？」

**什么时候会用到它**：

- 执行中能不能跟对方和解
- 和解后对方又不履行怎么办
- 执行担保怎么用

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
执行中能不能跟对方和解？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份离婚起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非借贷与执行问题**：借款、担保、抵押质押、诉讼时效、强制执行以外的领域（如劳动争议、婚姻家事、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于执行程序中的执行和解与执行担保，包括和解协议的达成、提交与中止执行，和解协议的变更与以物抵债的限制，对方不履行时恢复执行与另行起诉的选择，以及执行担保的提供方式、担保书内容、担保期间与暂缓执行期限届满后的处理。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 双方协商变更履行安排 | 是否依法变更主体、标的、期限、地点、方式 | 可以自愿达成和解协议，一般采用书面形式 |
| 和解协议需要进入执行程序 | 是否共同提交、一方提交对方认可，或记入笔录并签名盖章 | 符合的法院可以裁定中止执行 |
| 被执行人未按和解协议履行 | 选择恢复执行还是就和解协议起诉 | 恢复执行后不得再诉和解协议；起诉和解协议后原执行可被终结 |
| 判断恢复执行的期间 | 自和解协议约定履行期间最后一日起算 | 适用申请执行期间的规定，并向法院主张扣除已履行部分 |
| 提供担保换取暂缓执行 | 是否提交担保书并送交申请执行人、对方是否同意 | 法院可以决定暂缓执行及暂缓执行的期限 |
| 暂缓期限届满仍不履行 | 担保人是否有转移、隐藏、毁损担保财产等行为 | 可以恢复执行并直接裁定执行担保财产或保证人财产，以应履行部分为限 |

## 六、操作步骤

1. 谈和解前先梳理执行进展、已查封财产与对方履行能力
2. 把和解条件写成书面协议，明确金额、期限、方式与违约责任
3. 双方共同提交法院，或由执行人员记入笔录并签名盖章，使协议进卷宗
4. 在协议中争取担保条款，并由担保人向法院承诺自愿接受直接强制执行
5. 谨慎对待解除查封、扣押、冻结，最好与付款进度分步挂钩
6. 对方违约后，在期限内选择恢复执行或就和解协议起诉，二者不宜并用
7. 采用执行担保的，核对担保书内容、担保期间与暂缓执行期限两个时间点

## 七、常见误区

- 只达成口头和解，不进卷宗，对方违约后举证困难
- 一揽子解除全部查封后再谈分期，失去控制手段
- 以物抵债的和解写成协议就以为能够直接办理过户
- 恢复执行与就和解协议起诉同时推进，导致诉讼被不予受理
- 忽略恢复执行期间自和解协议约定履行期最后一日起算这一节点
- 担保书不记载担保期间或记载不明，错过一年担保期间而无法执行担保财产

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
