# 检查表

## 事实与材料自查

- [ ] 和解协议是否采用书面形式并由双方签署
- [ ] 协议是否已共同提交法院或记入笔录并签名盖章
- [ ] 是否明确变更的主体、标的、期限、地点与方式
- [ ] 是否约定担保条款与自愿接受直接强制执行的承诺
- [ ] 解除查封、扣押、冻结是否与履行进度挂钩
- [ ] 恢复执行期间是否已从和解约定履行期最后一日起算
- [ ] 是否已决定走恢复执行还是另行起诉，避免二者并用
- [ ] 执行担保的担保书内容是否完整、担保期间是否明确

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
