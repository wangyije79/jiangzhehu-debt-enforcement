# 申请执行立案

> 执行材料、管辖与执行费用

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「申请强制执行要交什么材料？」「该去哪个法院申请执行？」

**什么时候会用到它**：

- 申请强制执行要交什么材料
- 该去哪个法院申请执行
- 申请执行要不要交钱

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
申请强制执行要交什么材料？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份离婚起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非借贷与执行问题**：借款、担保、抵押质押、诉讼时效、强制执行以外的领域（如劳动争议、婚姻家事、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于执行立案环节的全流程准备：申请执行的材料清单与形式要求、授权委托与特别授权、执行案件的管辖判断与级别管辖、重复申请的处理、保全财产向执行法院的移交衔接、管辖异议的提出与救济，以及执行申请费与保全申请费的负担规则。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 准备材料 | 文书类型是判决、仲裁裁决还是公证债权文书 | 判决与调解书提交副本即可；仲裁裁决须附仲裁条款合同书或仲裁协议书；公证债权文书须另附执行证书 |
| 确定管辖 | 执行依据是法院裁判还是其他法律文书 | 法院裁判由第一审法院或与其同级的被执行财产所在地法院执行；其他法律文书由被执行人住所地或被执行财产所在地法院执行 |
| 想去财产所在地法院 | 能否提供该辖区有可供执行财产的证明材料 | 能提供的可以受理；不能提供的应在住所地或其他有管辖权法院申请 |
| 多个法院都有管辖权 | 是否已向其他法院申请 | 只能择一申请，向两个以上法院申请的由最先立案的法院管辖，重复立案的应撤销 |
| 委托他人办理 | 是否涉及放弃变更权利、执行和解或收取执行款 | 涉及上述事项的必须取得特别授权，否则代理行为无法完成 |
| 担心立案费用 | 属于执行申请费还是保全申请费 | 执行申请费不由申请人预交、执行后交纳且由被执行人负担；保全申请费由申请人预交 |

## 六、操作步骤

1. 核对生效证明与履行期届满日，确认申请执行期间未过
2. 按文书类型备齐材料：申请执行书、文书副本、身份证明、附加文件
3. 撰写申请执行书并填写财产调查表，写明已知财产状况与具体线索
4. 判断管辖法院：第一审法院、被执行人住所地或财产所在地法院
5. 涉及特别事项的办理特别授权，避免代为和解收款失败
6. 提交材料并取得立案回执，七日内跟进立案结果
7. 立案后申请续行保全或移送保全财产，保证查控不中断

## 七、常见误区

- 把公证债权文书的合同公证书当作执行依据，缺少执行证书
- 授权委托书只写一般授权，无法代为和解或收款
- 向两个法院同时递交，导致后立案件被撤销
- 向财产所在地法院申请却拿不出该辖区有财产的证明材料
- 忽略与第一审法院同级这一限定，选错级别管辖
- 立案后忘记办理保全财产移交，查封到期失效

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
