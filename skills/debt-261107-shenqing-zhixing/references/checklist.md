# 检查表

## 事实与材料自查

- [ ] 文书是否生效、履行期是否已届满
- [ ] 申请执行书是否写明理由、事项、执行标的与财产状况
- [ ] 身份证明是否齐全，法人材料是否包含法定代表人身份证明
- [ ] 仲裁类是否附仲裁条款合同书或仲裁协议书
- [ ] 公证类是否提交证明履行情况的执行证书
- [ ] 授权委托书是否为特别授权并写明权限与期限
- [ ] 财产线索是否已按调查表要求填写具体
- [ ] 管辖法院是否已确认，是否存在重复立案风险

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
