# 分析框架与操作方法

## 判断逻辑

### 节点 1：准备材料

- **判断标准**：文书类型是判决、仲裁裁决还是公证债权文书
- **处理结论**：判决与调解书提交副本即可；仲裁裁决须附仲裁条款合同书或仲裁协议书；公证债权文书须另附执行证书

### 节点 2：确定管辖

- **判断标准**：执行依据是法院裁判还是其他法律文书
- **处理结论**：法院裁判由第一审法院或与其同级的被执行财产所在地法院执行；其他法律文书由被执行人住所地或被执行财产所在地法院执行

### 节点 3：想去财产所在地法院

- **判断标准**：能否提供该辖区有可供执行财产的证明材料
- **处理结论**：能提供的可以受理；不能提供的应在住所地或其他有管辖权法院申请

### 节点 4：多个法院都有管辖权

- **判断标准**：是否已向其他法院申请
- **处理结论**：只能择一申请，向两个以上法院申请的由最先立案的法院管辖，重复立案的应撤销

### 节点 5：委托他人办理

- **判断标准**：是否涉及放弃变更权利、执行和解或收取执行款
- **处理结论**：涉及上述事项的必须取得特别授权，否则代理行为无法完成

### 节点 6：担心立案费用

- **判断标准**：属于执行申请费还是保全申请费
- **处理结论**：执行申请费不由申请人预交、执行后交纳且由被执行人负担；保全申请费由申请人预交

## 操作步骤

1. 核对生效证明与履行期届满日，确认申请执行期间未过
2. 按文书类型备齐材料：申请执行书、文书副本、身份证明、附加文件
3. 撰写申请执行书并填写财产调查表，写明已知财产状况与具体线索
4. 判断管辖法院：第一审法院、被执行人住所地或财产所在地法院
5. 涉及特别事项的办理特别授权，避免代为和解收款失败
6. 提交材料并取得立案回执，七日内跟进立案结果
7. 立案后申请续行保全或移送保全财产，保证查控不中断

## 常见误区

- 把公证债权文书的合同公证书当作执行依据，缺少执行证书
- 授权委托书只写一般授权，无法代为和解或收款
- 向两个法院同时递交，导致后立案件被撤销
- 向财产所在地法院申请却拿不出该辖区有财产的证明材料
- 忽略与第一审法院同级这一限定，选错级别管辖
- 立案后忘记办理保全财产移交，查封到期失效

## 说明

立案是执行的第一道闸门，两个动作最关键：材料按类型备齐，管辖按依据选对。这两步做对，后面才有查控效率可谈。金额与费用问题，立案时一次问清，不要拖到执行款到账才发现被扣。
