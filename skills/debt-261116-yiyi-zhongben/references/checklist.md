# 检查表

## 事实与材料自查

- [ ] 是否已区分执行行为异议与案外人标的异议
- [ ] 异议请求是否具体到某一执行行为或某一执行标的
- [ ] 提出异议的时间是否仍在法定期限内
- [ ] 案外人异议的权利人证明材料是否按第二十五条准备
- [ ] 异议事由是否一次性提全，避免二次提出不被受理
- [ ] 是否评估过提供担保以请求停止相应处分措施
- [ ] 收到终本告知时是否已书面表达意见并留痕
- [ ] 终本后是否已按期申请续行查封、扣押、冻结

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
