# 执行异议与终结本次执行

> 执行异议、案外人异议与终本恢复

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「财产被执行错了怎么办？」「执行异议要怎么提？」

**什么时候会用到它**：

- 财产被执行错了怎么办
- 执行异议要怎么提
- 终本案件是不是就不管了

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
财产被执行错了怎么办？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份离婚起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非借贷与执行问题**：借款、担保、抵押质押、诉讼时效、强制执行以外的领域（如劳动争议、婚姻家事、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于执行程序中的执行异议与终结本次执行程序，包括执行行为异议与案外人标的异议的区分、异议主体与提出期限、书面审查与听证程序、权利人的判断标准，以及终本的法定条件、终本前的告知、终本后的恢复执行与续行查封、冻结。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 认为执行行为违法 | 是否属于查封、扣押、冻结、拍卖、变卖等措施或法定程序违法 | 按执行行为异议审查，异议成立裁定撤销或改正 |
| 认为执行标的属于自己 | 是否属于案外人、是否在标的执行终结前提出 | 按案外人异议审查，成立则裁定中止对该标的的执行 |
| 案外人异议的审查内容 | 是否系权利人、权利是否合法真实、能否排除执行 | 三项均具备的，才能阻却执行 |
| 对异议裁定不服 | 认为原判决、裁定错误，还是与原判决、裁定无关 | 前者走审判监督程序；后者十五日内向法院提起诉讼 |
| 收到终本告知或裁定 | 是否同时符合终本的五个法定条件 | 不符合的可以提出执行异议 |
| 终本后主张权利 | 是否发现可供执行财产、查封冻结是否需要续行 | 发现财产的可以申请恢复执行，不受申请执行时效期间限制；查封需及时续行 |

## 六、操作步骤

1. 先区分是执行行为异议还是案外人标的异议，两条路程序不同
2. 核对提出异议的时间是否在期限内：行为异议在执行程序终结前，标的异议在标的执行终结前
3. 准备书面申请书，写明具体的异议请求、事实与理由，并附证据材料
4. 按第二十五条的登记、登记簿、账户名称等标准准备权利人的证明材料
5. 积极配合书面审查与听证，一次把异议事由提全
6. 收到终本告知或裁定，逐条核对五个法定条件是否同时满足
7. 终本后持续提供财产线索并申请恢复执行，同时按期申请续行查封、冻结

## 七、常见误区

- 把两类异议混在一起提，导致程序反复
- 认为提异议就会停止执行，忽略异议审查期间不停止执行
- 异议事由分几次提，撤回或被驳回后再次提出被不予受理
- 案外人异议错过标的执行终结前这一时间点，标的已处分
- 收到终本告知不表达意见，事后主张程序欠缺时缺少记录
- 终本后不申请续行查封、扣押、冻结，期限届满效力消灭

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
