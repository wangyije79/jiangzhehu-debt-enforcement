# 担保人要不要还钱

> 保证方式、保证期间与追偿

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「担保人到底承担什么责任？」「一般保证和连带责任保证差在哪？」

**什么时候会用到它**：

- 担保人到底承担什么责任
- 一般保证和连带责任保证差在哪
- 保证期间过了还要还吗

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
担保人到底承担什么责任？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份离婚起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非借贷与执行问题**：借款、担保、抵押质押、诉讼时效、强制执行以外的领域（如劳动争议、婚姻家事、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于保证合同的签订与审查、保证方式的判断与推定、一般保证先诉抗辩权的适用、连带责任保证的主张路径、保证范围的确定、保证期间的计算与届满后果、保证债务诉讼时效的起算，以及保证人抗辩权与追偿权的行使。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 保证合同未写保证方式 | 是否明确约定连带责任保证 | 没有约定或约定不明的按一般保证承担保证责任 |
| 债权人要求一般保证人承担责任 | 主合同是否已经审判或仲裁、是否已对债务人财产强制执行仍不能履行 | 未走完程序的保证人可主张先诉抗辩权；出现法定四种情形之一的除外 |
| 债权人要求连带责任保证人承担责任 | 是否在保证期间内提出请求 | 期间内请求的，保证人应在保证范围内承担责任；未请求的，保证人不再承担 |
| 保证合同未约定保证期间 | 主债务履行期限届满日为何时 | 保证期间为主债务履行期限届满之日起六个月，不发生中止、中断和延长 |
| 保证期间届满 | 债权人是否完成法定主张动作 | 一般保证未起诉或申请仲裁、连带保证未请求保证人承担的，保证人不再承担保证责任 |
| 保证人已承担责任 | 承担范围与有无约定 | 有权在承担保证责任的范围内向债务人追偿，并可主张债务人对债权人的抗辩 |

## 六、操作步骤

1. 先看保证条款：保证方式、保证范围、保证期间三项是否写明
2. 没有写方式或写得不明的，按一般保证处理，据此确定主张路径
3. 确定主债务履行期限届满日，据此计算保证期间起算点
4. 核对约定的保证期间是否有效，无效或未约定的按六个月计算
5. 按保证方式在期间内完成对应动作：起诉或申请仲裁，或向保证人书面主张
6. 保留送达凭证，证明主张在期间内到达
7. 期间内主张后计算保证债务诉讼时效；主债务变更、展期的核查是否取得保证人书面同意

## 七、常见误区

- 只写“担保人”三个字，误以为是连带责任保证
- 以为保证期间可以像诉讼时效一样靠催款中断或延长
- 一般保证只在期间内口头催款，没有提起诉讼或申请仲裁
- 连带保证只向债务人催收，从未向保证人主张
- 约定的保证期间与主债务履行期限同时届满，被认定为没有约定
- 把保证期间与保证债务的诉讼时效混为一谈，顺序颠倒

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
