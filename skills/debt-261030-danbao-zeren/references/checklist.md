# 检查表

## 事实与材料自查

- [ ] 保证方式是否明确写为连带责任保证，还是留了空白
- [ ] 保证范围是否写明，还是默认覆盖利息、违约金与实现债权的费用
- [ ] 保证期间是否约定，约定的起算点是否有效
- [ ] 主债务履行期限届满日是否明确、是否有书面记录
- [ ] 是否在保证期间内完成了该种保证要求的动作
- [ ] 主张是否有送达凭证，能否证明在期间内到达保证人
- [ ] 主债务有无变更或展期，是否取得保证人书面同意
- [ ] 保证人是否为公司，是否已履行内部决议程序

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
