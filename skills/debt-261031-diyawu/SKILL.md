# 抵押与质押

> 抵押登记效力、抵押物转让与质押区别

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「抵押不办登记还有效吗？」「抵押的房子能不能卖？」

**什么时候会用到它**：

- 抵押不办登记还有效吗
- 抵押的房子能不能卖
- 质押和抵押有什么区别

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
抵押不办登记还有效吗？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份离婚起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非借贷与执行问题**：借款、担保、抵押质押、诉讼时效、强制执行以外的领域（如劳动争议、婚姻家事、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于抵押权的设立与登记效力判断、动产抵押与不动产抵押的区分、抵押财产转让的处理、同一财产多个担保权的清偿顺序、抵押权行使期间，以及动产质押的交付设立、权利质押的范围与设立方式、抵押与质押的选择与比较。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 以不动产设定抵押 | 是否办理抵押登记 | 抵押权自登记时设立，未登记则抵押权未产生，只能作为普通债权主张 |
| 以动产设定抵押 | 是否办理抵押登记 | 抵押权自抵押合同生效时设立，未登记不得对抗善意第三人 |
| 同一财产上有多个抵押权 | 各抵押权是否登记、登记的先后时间 | 已登记的按登记时间先后清偿，已登记的先于未登记，均未登记的按债权比例 |
| 抵押人想转让抵押财产 | 是否通知抵押权人、转让是否可能损害抵押权 | 转让有效且抵押权不受影响；抵押权人可请求提前清偿或者提存转让价款 |
| 以动产设定质押 | 质押财产是否实际交付质权人占有 | 质权自出质人交付质押财产时设立，未交付则不产生质权 |
| 以权利设定质押 | 该权利有无权利凭证 | 有凭证的自凭证交付时设立；无凭证的自办理出质登记时设立 |

## 六、操作步骤

1. 先分类：标的是不动产、动产还是权利，决定适用登记还是交付
2. 订立书面担保合同，写明被担保债权、履行期限、担保财产与担保范围
3. 不动产抵押：办理抵押登记，取得登记证明
4. 动产抵押：优先办理登记，注意不得对抗正常经营活动中的买受人
5. 动产质押：完成实际交付，制作交接清单并留存影像资料
6. 权利质押：核实有无权利凭证，据以交付凭证或办理出质登记
7. 同一财产上多重担保按登记与交付时间排序，并登记主债权到期日、安排行使担保物权

## 七、常见误区

- 签了抵押合同就放款，不办不动产抵押登记
- 把动产抵押未登记当成完全没有抵押权，或者当成可以对抗所有人
- 质押合同签了但没有实际交付质押财产
- 权利质押不看有无权利凭证，混淆交付与登记两种设立方式
- 股权、基金份额出质不去办理出质登记
- 抵押权长期不行使，主债权诉讼时效届满后无法获得保护

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
