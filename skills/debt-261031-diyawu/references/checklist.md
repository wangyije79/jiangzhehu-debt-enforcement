# 检查表

## 事实与材料自查

- [ ] 标的类型是否判断准确，确定适用登记还是交付
- [ ] 担保合同是否采用书面形式，条款是否完整
- [ ] 不动产抵押是否已办登记并取得登记证明
- [ ] 动产抵押是否已办登记，是否了解对抗力的边界
- [ ] 质押财产是否已实际交付，是否有交接清单
- [ ] 权利质押是否核实权利凭证并完成交付或登记
- [ ] 多重担保的时间先后是否已经核对清楚
- [ ] 主债权到期日与行使担保物权的期间是否已登记

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
