# 限制高消费

> 限高范围、申请方式与解除途径

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「限制高消费到底限制了什么？」「怎么申请限制对方高消费？」

**什么时候会用到它**：

- 限制高消费到底限制了什么
- 怎么申请限制对方高消费
- 被限高了怎么解除

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
限制高消费到底限制了什么？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份离婚起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非借贷与执行问题**：借款、担保、抵押质押、诉讼时效、强制执行以外的领域（如劳动争议、婚姻家事、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于金钱给付类执行案件中对被执行人采取与解除限制消费措施的判断，包括限高的纳入条件、九项限制消费的具体范围、单位被限高时法定代表人等人员的连带限制、因生活或经营必需的例外申请、申请流程与解除的三条路径。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 被执行人未按执行通知履行给付义务 | 是否已发出执行通知并届期未履行 | 人民法院可以采取限制消费措施，并发出限制消费令 |
| 被执行人已被纳入失信名单 | 是否已被纳入失信被执行人名单 | 人民法院应当对其采取限制消费措施，属于必然结果 |
| 判断某项消费能否进行 | 是否属于非生活和工作必需的消费 | 九项列举之内的不得进行，兜底项按实质判断 |
| 被执行人是单位 | 谁是法定代表人、主要负责人、影响债务履行的直接责任人员、实际控制人 | 上述人员一并受限；因私消费以个人财产的可以申请准许 |
| 因生活或经营必需需要消费 | 是否事前向执行法院提出申请并获批准 | 获批后方可进行；先消费后解释可能被认定为拒不履行 |
| 想解除限制消费令 | 是否履行完毕、提供确实有效担保或取得申请执行人同意 | 履行完毕应当解除；担保或对方同意的可以解除 |

## 六、操作步骤

1. 核对执行进展：执行通知是否已发出、被执行人是否届期未履行
2. 区分“可以限高”与“纳入失信后应当限高”，判断适用哪一条
3. 需要申请限高的，向执行法院提交书面申请，写明请求、事实与财产线索
4. 跟进限制消费令是否签发、协助执行通知书是否送达、是否公告
5. 被执行人是单位的，逐人核对是否波及法定代表人、主要负责人等个人
6. 确因生活或经营必需需要消费的，事前提交申请并保留批准材料
7. 申请解除的，按履行完毕、提供担保、对方同意三条路径准备材料

## 七、常见误区

- 以为限高只针对被执行人本人，忽略单位被限高时法定代表人的连带限制
- 以为被限高就等于上了失信名单，或以为要先失信才可能被限高
- 只口头向法院反映对方高消费，不提交书面申请与线索
- 因生活或经营必需先消费再解释，被认定为违反限制消费令
- 解除限高后不核对失信信息，名单仍挂在公示渠道
- 拿到“对方被限高了”的说法就以为措施已落地，不核实是否已送达协助执行单位

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
