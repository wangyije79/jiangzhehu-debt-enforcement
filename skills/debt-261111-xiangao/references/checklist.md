# 检查表

## 事实与材料自查

- [ ] 是否已确认执行通知已发出且被执行人届期未履行
- [ ] 限制消费令是否载明限制期间、项目与法律后果
- [ ] 是否向义务协助单位送达协助执行通知书或进行公告
- [ ] 被执行人为单位时，是否已核对被连带限制的人员范围
- [ ] 因生活或经营必需的消费，是否事前申请并获批准
- [ ] 解除的依据属于履行完毕、提供担保还是对方同意
- [ ] 解除后是否已取得法院的通知或公告，而非只看购票是否恢复
- [ ] 是否同步处理失信名单信息，避免只解开限高

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
