# 追加与变更被执行人

> 股东出资、关联主体与申请材料

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「公司没钱能不能找股东要？」「哪些情况可以追加被执行人？」

**什么时候会用到它**：

- 公司没钱能不能找股东要
- 哪些情况可以追加被执行人
- 追加要准备什么材料

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
公司没钱能不能找股东要？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份离婚起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非借贷与执行问题**：借款、担保、抵押质押、诉讼时效、强制执行以外的领域（如劳动争议、婚姻家事、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于执行程序中变更、追加被执行人与其他执行当事人，包括未缴纳或未足额缴纳出资、抽逃出资、未依法出资即转让股权、一人公司财产混同、未经清算注销、无偿接受财产、书面承诺清偿与行政命令调拨等情形的判断，以及申请材料、听证程序与后续救济路径。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 公司为被执行人但无财产可供执行 | 是否已确认财产不足以清偿债务 | 未确认财产不足的，不能直接追加股东 |
| 股东未缴纳或未足额缴纳出资 | 是否存在认缴未实缴、出资期限届至等情形 | 在尚未缴纳出资的范围内承担责任 |
| 股东抽逃出资或未出资即转让股权 | 资金是否流出且无对价、转让时出资是否已履行 | 在抽逃或未依法出资的范围内承担责任 |
| 被执行人为一人有限责任公司 | 股东能否证明公司财产独立于自己的财产 | 不能证明的，对公司债务承担连带责任 |
| 公司未经清算即办理注销登记 | 是否导致公司无法进行清算 | 可以追加有限责任公司股东、股份有限公司董事和控股股东，承担连带清偿责任 |
| 第三人曾书面承诺代被执行人清偿 | 承诺是否以书面作出、范围如何约定 | 在承诺范围内承担责任 |

## 六、操作步骤

1. 调取公司工商档案，核对章程、股东认缴与实缴信息及历次变更
2. 固定“财产不足以清偿”的材料：终本裁定、财产查询反馈、无财产记录
3. 按主张的情形匹配对应条款，逐条核对是否需要额外证据
4. 准备书面申请与证据材料，按一条主张一组证据整理
5. 申请变更、追加的同时申请对被申请人财产采取查封、扣押、冻结措施
6. 参加合议庭审查与听证，按证据目录逐项说明事实与法律依据
7. 对裁定不服的，区分十日复议与十五日执行异议之诉，按期提出

## 七、常见误区

- 未确认公司财产不足就申请追加股东
- 把股东的有限责任当成无条件连带，请求写成全额兜底
- 只提交判决书和执行裁定，不提供工商档案与出资凭证
- 忽略“未依法履行出资义务即转让股权”这条打逃债的路径
- 一人公司案件中误以为要自己证明财产混同，忽略证明责任在股东
- 错过十日复议或者十五日执行异议之诉的期限

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
