# 分析框架与操作方法

## 判断逻辑

### 节点 1：公司为被执行人但无财产可供执行

- **判断标准**：是否已确认财产不足以清偿债务
- **处理结论**：未确认财产不足的，不能直接追加股东

### 节点 2：股东未缴纳或未足额缴纳出资

- **判断标准**：是否存在认缴未实缴、出资期限届至等情形
- **处理结论**：在尚未缴纳出资的范围内承担责任

### 节点 3：股东抽逃出资或未出资即转让股权

- **判断标准**：资金是否流出且无对价、转让时出资是否已履行
- **处理结论**：在抽逃或未依法出资的范围内承担责任

### 节点 4：被执行人为一人有限责任公司

- **判断标准**：股东能否证明公司财产独立于自己的财产
- **处理结论**：不能证明的，对公司债务承担连带责任

### 节点 5：公司未经清算即办理注销登记

- **判断标准**：是否导致公司无法进行清算
- **处理结论**：可以追加有限责任公司股东、股份有限公司董事和控股股东，承担连带清偿责任

### 节点 6：第三人曾书面承诺代被执行人清偿

- **判断标准**：承诺是否以书面作出、范围如何约定
- **处理结论**：在承诺范围内承担责任

## 操作步骤

1. 调取公司工商档案，核对章程、股东认缴与实缴信息及历次变更
2. 固定“财产不足以清偿”的材料：终本裁定、财产查询反馈、无财产记录
3. 按主张的情形匹配对应条款，逐条核对是否需要额外证据
4. 准备书面申请与证据材料，按一条主张一组证据整理
5. 申请变更、追加的同时申请对被申请人财产采取查封、扣押、冻结措施
6. 参加合议庭审查与听证，按证据目录逐项说明事实与法律依据
7. 对裁定不服的，区分十日复议与十五日执行异议之诉，按期提出

## 常见误区

- 未确认公司财产不足就申请追加股东
- 把股东的有限责任当成无条件连带，请求写成全额兜底
- 只提交判决书和执行裁定，不提供工商档案与出资凭证
- 忽略“未依法履行出资义务即转让股权”这条打逃债的路径
- 一人公司案件中误以为要自己证明财产混同，忽略证明责任在股东
- 错过十日复议或者十五日执行异议之诉的期限

## 说明

追加这条线的胜负几乎在材料上：一层是“公司财产不足”的证据，一层是出资、抽逃、注销的工商与资金证据。零散提交不如按“一条主张一组证据”打包，听证上也站得住。另要一并申请保全，并区分复议与异议之诉。
