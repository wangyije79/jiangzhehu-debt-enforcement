# 检查表

## 事实与材料自查

- [ ] 是否已确认被执行人财产不足以清偿债务
- [ ] 工商档案、股东出资与变更记录是否已调取
- [ ] 所主张的情形是否对应到具体条款
- [ ] 抽逃出资的资金流水等凭证是否已固定
- [ ] 一人公司案件中是否已就财产混同准备线索
- [ ] 注销案件的清算材料与承诺文件是否已调取
- [ ] 是否已同步提交财产保全申请
- [ ] 是否已区分十日复议与十五日异议之诉的救济路径

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
