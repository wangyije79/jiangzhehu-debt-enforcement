# 检查表

## 事实与材料自查

- [ ] 是否已确定时效的起算日与届满日
- [ ] 借条上关于还款时间的全部文字是否都看过了
- [ ] 是否留存了至少一次能证明到达的催收凭证
- [ ] 催收内容是否写明了本金、利息与截止日期
- [ ] 对方的还款、承诺、担保是否已单独固定
- [ ] 是否核对过抵押等担保的行使期间是否受影响
- [ ] 是否避免了在沟通中主动提“已经过期”
- [ ] 决定起诉的，是否已经确认提交时间

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
