# 催款与诉讼时效

> 时效起算、中断与超过时效的补救

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「借条放多久不催就过期？」「怎么催款才能中断时效？」

**什么时候会用到它**：

- 借条放多久不催就过期
- 怎么催款才能中断时效
- 过了时效还能不能要回来

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
借条放多久不催就过期？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份离婚起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非借贷与执行问题**：借款、担保、抵押质押、诉讼时效、强制执行以外的领域（如劳动争议、婚姻家事、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于自然人之间借款的诉讼时效判断与催收留痕，包括有约定还款期限、未约定还款期限、分期履行三类借条的起算点认定；也适用于已经拖了较长时间、担心时效届满、需要判断还能不能主张权利，以及催收方式如何选择、如何固定中断证据的场合。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 借条写了还款日期 | 还款日期是否已届满 | 时效从还款日期届满之日起算 |
| 借条未写还款日期 | 能否依民法典第五百一十条、第五百一十一条确定履行期限 | 能确定的从履行期限届满之日起算；不能确定的从催告宽限期届满之日起算 |
| 第一次催告时对方明确拒付 | 有无明确表示不履行的记录 | 时效从对方明确表示不履行义务之日起算 |
| 约定分期还款 | 每期履行期限是否已届满 | 通常按每一期的履行期限分别计算时效 |
| 想通过催收中断时效 | 催收能否证明出发出并到达对方 | 能证明的（含信件、数据电文到达）产生中断效力，中断后重新计算 |
| 时效已经届满 | 对方是否提出时效抗辩、有没有自愿履行或书面承诺 | 对方未提抗辩的法院不主动释明；自愿履行或承诺履行后不得再抗辩 |

## 六、操作步骤

1. 先把借条、转账凭证、聊天记录里的所有时间点摘出来
2. 判断属于有约定、无约定还是分期履行，确定起算规则
3. 算出起算日与三年届满日，把余量写下来
4. 选择催收方式：面谈签字、短信邮件、快递催收函
5. 每一次催收都留存可证明发出并到达的凭证
6. 把对方的还款、承诺、担保等行为单独归档
7. 做一张时效时间轴，把每个中断点标上去

## 七、常见误区

- 以为没写还款日期就可以无限期拖下去
- 只做口头催收，事后拿不出任何凭证
- 把催收函寄出就算送达，不留面单和签收记录
- 只催一部分，却以为中断效力不及于剩余债权
- 在沟通中主动说出“已经过期了”
- 只盯着本金，忽略抵押等担保的行使期间

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
