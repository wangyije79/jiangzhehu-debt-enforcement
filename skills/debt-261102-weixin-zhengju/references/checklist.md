# 检查表

## 事实与材料自查

- [ ] 原始载体是否完好，近期有没有清理或更换设备
- [ ] 是否已导出完整对话，而不是只有零散截图
- [ ] 聊天对象身份是否有材料可以对应到本人
- [ ] 关键对话有没有被裁掉上下文
- [ ] 是否保留了对方的还款、付息或承诺还款的内容
- [ ] 是否对关键记录做过正式固定
- [ ] 是否做过至少一次能证明到达的催收
- [ ] 材料是否按时间编号并写明证明目的

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
