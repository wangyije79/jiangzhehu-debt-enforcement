# 微信聊天记录当证据

> 聊天记录取证、删除与视听资料

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「微信聊天记录怎么用才有效？」「对方删了好友怎么办？」

**什么时候会用到它**：

- 微信聊天记录怎么用才有效
- 对方删了好友怎么办
- 语音和视频要怎么固定

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
微信聊天记录怎么用才有效？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份离婚起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非借贷与执行问题**：借款、担保、抵押质押、诉讼时效、强制执行以外的领域（如劳动争议、婚姻家事、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于以微信、短信、电子邮件等聊天记录，以及语音条、通话录音、视频作为主要证据的借贷纠纷；也适用于对方删除好友、拉黑、注销账号、记录被清理或设备更换等情形下，需要判断电子材料还能不能用、需要补哪些材料、怎么固定才更稳妥的场合。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 手上只有聊天记录 | 账号能否对应到被告本人、内容是否完整连贯 | 能锁定身份且内容完整的可作证据；不能的需转账凭证等材料补强 |
| 对方提出“这不是我的号” | 有没有实名信息、转账凭证或独有信息可用于印证 | 有印证材料的可以认定账号归属；没有的可能不被采信 |
| 记录只截了片段 | 是否保留完整对话链，包括对方辩解 | 片段式记录可信度下降，应补充完整原始记录 |
| 对方已删除好友或拉黑 | 原始载体是否完好、有无备份或固定记录 | 原始载体完好的仍可提交；已损毁的尽快做恢复或固定 |
| 手上有语音条或视频 | 能否识别说话人、内容是否完整、取得方式是否合法 | 三项齐全的可作为认定参考；缺项的需要补强 |
| 聊天中对方承认借款或承诺还款 | 内容是否到达对方、能否证明发送与到达 | 可作为主张权利与同意履行的依据，影响时效计算 |

## 六、操作步骤

1. 保护原始载体：不换设备、不清缓存、不卸载重装、不做恢复出厂设置
2. 按时间顺序导出完整对话，另做一份备份留底
3. 留存账号画像：昵称、微信号、头像、手机号一并保存
4. 用转账凭证或独有信息建立账号与被主张人之间的对应
5. 把金额、借款、还款时间等关键对话标出来并编号
6. 对关键记录做公证或存证平台固定，明确固定时间
7. 用短信、电子邮件或快递补一次能证明到达的催收

## 七、常见误区

- 只截对自己有利的几句话，把上下文裁掉
- 换手机或清理数据，导致原始记录灭失
- 只凭昵称主张权利，无法证明账号属于谁
- 把转码压缩过的语音或视频当成原始文件提交
- 聊天里催过款但没有保留发送与到达的记录
- 以侵害他人权益的方式取证，材料反被排除

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
