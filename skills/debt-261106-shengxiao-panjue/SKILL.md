# 拿到判决之后

> 判决生效、申请执行期限与执行依据

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「判决生效了对方还不还怎么办？」「申请执行有没有时间限制？」

**什么时候会用到它**：

- 判决生效了对方还不还怎么办
- 申请执行有没有时间限制
- 哪些文书能直接申请执行

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
判决生效了对方还不还怎么办？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份离婚起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **地域**：本技能以中国大陆法律为基础，案例与操作口径侧重上海、江苏、浙江。其他地区裁审尺度可能不同。
- **时间**：法条核验日期见 `references/law.md` 页首，法律修订后需重新核验。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非借贷与执行问题**：借款、担保、抵押质押、诉讼时效、强制执行以外的领域（如劳动争议、婚姻家事、公司股权、刑事）不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、离婚协议、遗嘱等正式法律文书。

## 四、适用范围

适用于生效法律文书确定的权利如何兑现：判决、裁定、调解书、支付令、实现担保物权裁定、仲裁裁决、公证债权文书等执行依据的识别与申请，申请执行期间的起算、中止与中断，迟延履行利息的主张，以及执行中的查控、信用惩戒与终本后恢复执行的衔接。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 判决已生效对方不履行 | 是否已过文书指定的履行期 | 可以向第一审法院或与其同级的被执行的财产所在地法院申请执行 |
| 调解书、支付令、仲裁裁决、公证债权文书 | 文书是否有明确给付内容 | 主体与给付内容明确的可以申请执行；公证债权文书还须提交执行证书 |
| 准备申请执行 | 履行期最后一日是哪天 | 申请执行期间为二年，自履行期最后一日起算；分期履行自最后一期届满起算；未定期限自生效之日起算 |
| 期间快要届满 | 是否存在中断或中止事由 | 申请执行、达成和解、提出履行要求、对方同意履行均可中断并重新起算；最后六个月内因不可抗力等障碍可中止 |
| 对方有履行能力而拒不履行 | 是否符合纳入失信名单与限制消费条件 | 可以申请纳入失信名单、限制消费，必要时申请限制出境 |
| 一次执行未发现财产 | 是否符合终本条件 | 终本后被执行人继续履行；发现财产可申请恢复执行，且不受申请执行时效期间限制 |

## 六、操作步骤

1. 确认文书生效日期与履行期届满日，核验给付内容是否明确，不明则先行补正
2. 按文书类型准备材料：判决书与调解书副本、仲裁协议、公证债权文书与执行证书
3. 向有管辖权的法院提交申请执行书，注明所了解的被执行人财产状况
4. 立案后主动提交财产线索，配合法院查询、查封、冻结、扣划
5. 主张迟延履行期间的加倍债务利息，起算点为履行期届满之日
6. 对有履行能力而拒不履行的，申请纳入失信名单、限制消费、限制出境
7. 终本后建立跟进台账，发现财产立即申请恢复执行

## 七、常见误区

- 以为判决生效就能立即申请执行，忽略文书指定的履行期
- 分期履行的案件按第一期届满起算期间，导致期间核算错误
- 只口头催告不留证据，主张中断时拿不出材料
- 超过二年就自行放弃，不知道法院仍应受理
- 忽略迟延履行期间的加倍债务利息
- 终本后不再跟进，错失恢复执行的机会

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **口径要标地域**：说明地域差异时标明上海、江苏、浙江的口径，见 `references/cases.md`。
5. **缺材料不猜**：使用者未提供的关键事实（如登记时间、财产来源、出资情况、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体分割比例或赔偿金额、不替代正式法律意见。
7. **注意情绪与安全**：涉及家庭暴力、抢夺藏匿子女等情形，优先提示人身安全保护令等即时救济途径。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意

- 涉及金额较大，或已进入执行程序、需要保全或追加被执行人的

- 需要判断诉讼时效、管辖法院、执行期限等程序节点的
