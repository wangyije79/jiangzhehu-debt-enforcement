# 检查表

## 事实与材料自查

- [ ] 文书是否已经生效，履行期是否已经届满
- [ ] 权利义务主体是否明确、给付内容是否明确
- [ ] 申请执行期间是否已核算，起算点是否确认
- [ ] 催告与履行记录是否已固定，能否证明中断
- [ ] 申请材料是否齐全，仲裁与公证类是否备妥附加文件
- [ ] 是否已提交被执行人财产线索
- [ ] 是否已申请迟延履行利息
- [ ] 是否已评估失信名单、限制消费等信用惩戒手段

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 地域口径是否标明了上海、江苏、浙江
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 涉及人身安全的是否提示了保护令等救济途径
- [ ] 涉及个案争议时是否提示了咨询律师
